# 工创赛 智能搬运小车 路径规划可视化方案
> 国大学生工程实践与创新能力大赛 - 物流搬运组路径规划仿真页面

## ✨ 项目介绍
网页端静态仿真，实现场地建模、障碍物加载、A*路径搜索、轨迹预览，用于赛前调试、方案验证。
无需部署后端，直接打开 `index.html` 运行。

## 🚀 使用方法
1. 下载仓库源码
2. 直接双击打开 `index.html`
3. 功能：设置起点/终点、添加障碍物、生成最优路径、播放小车运动轨迹

## 🧩 算法
- 路径算法：A*
- 地图：工创赛标准场地、φ100圆柱障碍物
- 适用：2027物流搬运赛道
